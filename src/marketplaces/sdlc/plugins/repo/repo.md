name: repo
description: Skills for keeping a repository's branches, worktrees and configuration tidy.
ap-kind: plugin
ap-version: 0.1.0
---

Skills that tend the repository itself rather than the code in it: proving a
branch is safe to delete before deleting it, finding the orphans left by
sessions that ended without cleaning up, and recording how a project is built
and tested.

Nothing here assumes a project layout, a planning system, or a CLI beyond git.
